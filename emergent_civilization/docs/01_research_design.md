# 01. 연구 설계 (Research Design)

## 연구 주제

> 최소한의 규칙만 제공된 환경에서 LLM 기반 다중 AI 에이전트는
> 자발적으로 사회를 형성할 수 있는가?

## 핵심 가설

| # | 가설 (H) | 귀무가설 (H₀) | 판정 지표 |
|---|----------|---------------|-----------|
| H1 | AI는 반복 행동을 통해 **직업(역할)** 을 자발적으로 분화시킨다 | 모든 에이전트의 행동 분포가 통계적으로 동일하다 | 에이전트별 행동 분포의 분산, 역할 엔트로피 |
| H2 | AI는 상황에 따라 **협력과 경쟁** 을 선택한다 | 협력/경쟁 비율이 자원 상황과 무관하다 | 자원 희소성 대비 협력 행동 상관 |
| H3 | AI는 거래를 통해 **경제(가격)** 를 형성한다 | 교환 비율이 무작위이며 수렴하지 않는다 | 자원쌍별 교환비의 시간적 수렴, 분산 감소 |
| H4 | AI는 반복 상호작용으로 **신뢰/평판** 을 형성한다 | 상대 선택이 과거 상호작용과 무관하다 | 신뢰 점수와 재거래 확률의 상관 |
| H5 | AI는 사회 유지를 위해 **규칙/제도** 를 제안·수용한다 | 규칙 제안이 발생하지 않거나 수용되지 않는다 | 규칙 제안 수, 수용률, 규칙 준수율 |

각 개발 단계(v0.x)는 하나의 가설을 검증 가능한 상태로 만드는 것을 목표로 한다
(→ `07_roadmap.md`).

## 방법론

### 독립 변수 (사람이 조작)
- 세계 크기 / 자원 밀도 / 재생 속도
- 에이전트 수 (10 → 100+)
- 에이전트 성격 분포 (`Personality`)
- 사용 LLM 모델 및 온도

### 종속 변수 (관찰 대상)
- `06_metrics.md` 에 정의된 창발 지표 전체

### 통제 변수
- 동일 시드에서의 재현성 (world/agent/engine 모두 seed 주입)
- **베이스라인 대조군**: 동일 환경에서 `HeuristicPolicy`(규칙 기반)로 구동한
  결과와, `LLMPolicy`(LLM 구동) 결과를 비교한다. 창발이라 부르려면 LLM
  집단의 지표가 규칙 기반 베이스라인과 **유의하게 달라야** 한다.

## "창발"의 조작적 정의

본 연구에서 창발(emergence)은 다음을 모두 만족하는 현상으로 정의한다.

1. **미프로그래밍성** — 해당 구조(직업, 가격, 규칙 등)가 코드에
   명시적으로 존재하지 않는다. `sim/` 은 세계·물질대사·행동 어휘만 정의하며
   직업·가격·법·동맹 클래스를 두지 않는다.
2. **지속성** — 일시적 우연이 아니라 여러 틱에 걸쳐 유지·강화된다.
3. **대조 유의성** — 규칙 기반 베이스라인 대비 통계적으로 구별된다.

이 세 조건을 모두 통과할 때에만 "AI가 스스로 만들었다"고 기술한다.

## 편향 통제 노트

- 프롬프트에 직업명·가격·법 같은 **사회 구조 어휘를 주입하지 않는다**
  (→ `05_prompt_and_decision_loop.md`). 힌트는 곧 프로그래밍이다.
- 관찰(observation)은 항상 **부분적·자기중심적**이다. 전역 상태를 주면
  에이전트가 설계자의 시야를 물려받는다 (→ `sim/observation.py`).
- 행동 어휘에는 `speak`, `trade`, `propose_rule` 같은 **가능성**만 열어두고,
  그것을 언제 쓸지는 강제하지 않는다.
