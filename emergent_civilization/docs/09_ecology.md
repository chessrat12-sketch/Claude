# 09. 생태계: 위협·주거·인간관계 (Ecology)

> "생태계가 너무 단순하다 — 위협도, 주거도, 인간관계도 없다." 이 문서는 그
> 비판에 대한 응답으로 추가된 substrate 확장이다. **여전히 사회 구조는
> 프로그래밍하지 않는다.** 위험과 필요를 만들 뿐, 그에 대한 사회적 대응
> (뭉치기·나누기·동맹)은 에이전트가 스스로 선택한다.

## 왜 이 세 가지인가 — 서로 맞물린 유인 구조

```
        위협(밤/포식자)                    "왜 협력하는가"에 대한 답
              │  외톨이는 물리고, 무리는 피해 반감
              ▼
        주거(은신처 build)  ◀── 목재·석재에 진짜 가치 부여
              │                    (식량 일변도 거래 문제 해소)
              ▼
        제작(도구 craft) ──▶ 채집 효율 ↑ ──▶ 역할 분화(H1)
              │
              ▼
        인간관계(give·trade·trust) ──▶ 동맹/평판/갈등
```

핵심은 **단일 유인이 아니라 사슬**이다. 위협이 은신처를 필요하게 만들고,
은신처가 재료를 값지게 만들고, 값진 재료가 거래·제작·분업을 합리적으로
만들며, 반복된 거래·선물이 신뢰와 동맹을 낳는다.

## 위협 (`sim/ecology.py`)

- **밤낮 주기**: `World.day_length`(기본 24틱), 마지막 40%가 밤(`is_night`).
- **노출 피해**: 밤에 은신처 밖 에이전트는 추가로 에너지를 잃는다.
- **포식자**: 밤에 가장자리에서 스폰(인구에 비례), 가장 가까운 **노출된**
  에이전트를 추격해 문다(`PREDATOR_BITE=14`).
  - **안전 수치**: 반경 1 안에 살아있는 이웃이 2명 이상이면 피해 **반감**.
  - **은신처 안**: 물지 못함.
  - 낮이 되면 물러난다.

이 규칙이 협력·주거의 **생존 유인**을 만든다. (스크린샷 예: "Esme bitten
(7 dmg, but the group blunted it)" — 무리를 지어 14→7로 반감된 순간.)

## 주거 (`build`, `sim/world.py: Structure`)

- `build`: 3 wood + 1 stone 를 소비해 현재 타일에 은신처를 세운다(owner 기록).
- 효과: 밤 포식자·노출 차단, 휴식 시 에너지 회복 강화(`REST_SHELTER_BONUS`).
- 소유권은 기록되지만 물리적으로는 그 위에 선 누구든 보호한다 → **재산/영역**
  개념의 씨앗(누가 무엇을 지었는가). 공유·배타는 향후 창발 관찰 대상.
- 부수 효과: 목재·석재가 비로소 값을 가져 **거래가 합리적**이 된다.

## 제작 (`craft`)

- `craft`: 2 wood + 1 stone → 도구(`Resource.TOOL`). 도구 보유 시 채집 +2.
- 재료를 도구로 바꾸는 선택이 생기며, 일부가 채집·일부가 제작·일부가 거래에
  특화되면 **분업(H1)** 이 행동 이력의 최빈값으로 관찰된다.

## 인간관계 (`give` + 신뢰 변동)

- `give`: 대가 없이 자원을 건넨다. 받는 쪽 신뢰 **+0.2**, 주는 쪽 **+0.1**.
  → 관대함이 평판을 만든다(굶주린 이웃을 도우면 신뢰를 얻음).
- 거래 성사: 양측 신뢰 **+0.1**.
- **동맹**: 상호 신뢰 ≥ 0.3 인 살아있는 쌍(`metrics.alliances`).
- **갈등**: 음의 신뢰(현재 substrate에는 도둑질·공격 행동이 없어 갈등은
  향후 행동 추가 시 자연 발생; 신뢰 필드는 음수까지 지원).
- 관찰에는 이웃의 `health`(가시적 고통)와 `trust` 가 노출되어, "고통받는
  신뢰하는 이웃을 도울지"를 에이전트가 결정할 수 있다.

## 측정 (metrics 추가분)

| 지표 | 의미 |
|------|------|
| `deaths_by_cause` | 기아·탈진·포식자 사망 분해 |
| `structures_built` / `tools_crafted` / `gifts` | 주거·제작·이타 행동량 |
| `predator_attacks` | 위협 압력 |
| `alliances` / `mean_trust` | 사회 관계망(동맹·평균 신뢰) |

## 연구 무결성 노트

- 추가된 것은 **위험과 가능성**뿐이다. "밤에 뭉쳐라", "은신처를 공유하라",
  "굶주린 자를 도와라" 같은 지시는 프롬프트·코드 어디에도 없다(→ `05`).
- 베이스라인(`HeuristicPolicy`)이 이들을 쓰는 것은 세계가 그렇게 하도록
  **유인**하기 때문이지, 강제하기 때문이 아니다. 창발 주장은 여전히 LLM 대
  베이스라인 대조로 검정한다.

## 향후 확장(같은 원리)

- 갈등: 도둑질(`steal`)·공격 행동 → 음의 신뢰·복수·규범(v0.7)의 토대.
- 계절/기근: 자원 재생률의 주기적 변동 → 비축·분배 규범 압력.
- 상속/가족: 사망 시 은신처·재산의 처리 → 제도의 창발.
